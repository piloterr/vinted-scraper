# Vinted Scraper API – code examples

Examples for every Vinted endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/item.sh`](curl/item.sh) | `bash item.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| cURL (Bash) | [`curl/user_info.sh`](curl/user_info.sh) | `bash user_info.sh` |
